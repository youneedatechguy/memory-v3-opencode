# Memory v3 — Phase 03B: Lean Simplification

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the overengineered Phase 3 lifecycle with a small v4 source-replacement design while preserving privacy, atomicity, chunking, handoffs, and retry safety.

**Architecture:** Each source is fully chunked and embedded in memory before one SQLite transaction replaces its prior rows, vectors, FTS entries, and file hash. Retrieval is owner/source filtered and graph-free. Direct memory remains temporary handoff storage only.

**Tech Stack:** Python 3.14, SQLite/FTS5/sqlite-vec, FastMCP, pytest
